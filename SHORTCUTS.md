# Dubbing Shortcuts

| Key | Function |
|---|---|
| A | Set A point (toggle) |
| S | Play from A point |
| D | Delete last recorded clip |
| W | Play last recorded clip |
| F | Hold to record, release to stop |
| R | Toggle Dub Mode / Watch Mode |
| Space | Play / Pause |
| Ctrl+Z | Undo last delete |
| ← → | Seek backward / forward 3s |
